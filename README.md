# EcoRide - Full Stack Project

![Project Status](https://img.shields.io/badge/Project%20Status-In%20Progress-orange?style=flat-square)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue?style=flat-square)](LICENSE)

**EcoRide** is an eco-friendly carpooling web application, designed to connect passengers and drivers who want to share rides. It offers a smooth, secure experience, focused on sustainable mobility.

## Tech Stack

- **Frontend**: React, TypeScript, CSS
- **Backend**: Node.js, Express.js, TypeScript
- **Database**: MySQL/Sequelize, MongoDB/Mongoose
- **Containerization**: Docker, Docker Compose
